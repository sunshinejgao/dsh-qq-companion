# 边界与已知限制

这个文档记录**做过但没做好的事**，以及**不该做的事**。写出来是为了让后来者不重复踩坑。

## 一、法律与许可

### SnowLuma 不能自动部署

它的 EULA 明确写了：不得把本体并入第三方安装包、不得通过自动化脚本部署。所以：

- 本仓库**不打包**它的任何文件
- 安装脚本**不会**帮你下载或启动它
- 部署文档要求你**手动双击 `launcher.bat`**

违反的后果不只是失效，可能连带 QQ 账号。别图省事。

### 音色模型不能公开分发

RVC 模型（游戏角色、动漫角色、真人）的**声音权利属于原作方或本人**。社区分享的模型多数处于灰色地带：

- 私人场合自娱：一般没人管
- 公开发布、商用、冒充本人：明确侵权

所以本仓库只提供**目录约定和加载代码**，不含任何 `.pth` / `.index`。

### 豆包语音合成的额度与合规

- 你用的是自己账号的额度，超出会计费
- 合成内容受《生成式人工智能服务管理暂行办法》约束，别用来伪造他人声音

## 二、技术限制

### RVC 唱歌的天花板

| 现象 | 原因 | 能不能修 |
|---|---|---|
| 高音破、撕裂 | 音色模型的训练音域不够 | ❌ 只能换模型或降调（`--pitch -2`） |
| 某些字"卡"一下 | 短音节上掉帧 | ⚠️ 部分能修（补缝 ≤80ms） |
| 咬字发糊 | 换声模型对辅音建模弱 | ⚠️ `protect` 提到 0.9 有改善 |
| 换声后不像原唱的情感 | RVC 只保音色不保表情 | ❌ 换带情感的 TTS 或直接不用 RVC |

**根本原因**：RVC 是把「内容」和「音色」解耦后再合成，解耦过程本身会丢信息。这不是参数能解决的。

### 静音门限的两个失败模式

按参考人声做门限能压掉前奏杂音，但阈值选不好会：

- **太严**：主歌里轻声的字被切掉 → 听起来"断断续续"
- **太松**：前奏的分离残留留着 → 听起来"沙沙的"

当前实现用「先划出整首歌的发声区间，区间内只掐长静音」来规避——牺牲了精确性，换稳定性。

### 洛雪自动化很脆

它没有公开 API（`/search` 需要鉴权且不稳定），所以走 CDP 操作 DOM：

- 依赖 DOM 结构（`class="h0ywb"` 这类混淆类名），**洛雪升级就可能全废**
- 音质弹窗的按钮文本变了也会失败
- 部分源本身下不动（返回 `Invalid URL`），只能逐行试

### CPU 上很慢

| 环节 | 4 分钟的歌 |
|---|---|
| demucs 分离 | 约 5 分钟 |
| RVC 换声 | 约 15 分钟（索引 98 MB 时更久） |
| 修复 + 混音 | 约 2 分钟 |

有 GPU 会快 10~20 倍，但 `rvc-python` 的 CUDA 版在 Windows 上装起来很折腾。

### 上下文成本

每次唤醒注入完整人格卡（约 6600 字 ≈ 2000 token）。这是"改卡立即生效"的代价。如果改用 `qq_get_prompt` 按需读取，能省 token，但改了卡不会立刻反映。

## 三、设计上的取舍

| 做了 | 没做 | 为什么 |
|---|---|---|
| 群聊裁剪版感情顾问 | 完整建档问卷 | 群里问 MBTI 太扫兴 |
| 只发第一段翻唱 | 6 段全发 | 刷屏 |
| 提醒只发群消息 | 打电话/推送 | 只做得到这个 |
| 每群独立记忆 | 跨群共享 | 串群很出戏 |
| 短句多气泡 | 长段落 | 长段落立刻像 AI |

## 四、已知 bug / 待办

- [ ] **说话和唱歌的音色可以不一致**：目前都指 `naxida`，但换音色需要重跑旧作品
- [ ] **翻唱任务没有断点续跑**：中途挂了要从分离开始
- [ ] **`lx-dom-download.mjs` 的 DOM 选择器是硬编码的**，洛雪升级会挂
- [ ] **补缝只处理能量缺口**，对"音高破裂"无效
- [ ] **`repair_dropouts` 的阈值是经验值**，对不同类型的歌表现不同
- [ ] **日记的"顺手记"和"正式日记"共用一个文件**，判断逻辑靠正则找 `## 说说`，脆弱

## 五、如果你要改

几个容易改错的地方：

1. **别在 `# === qq-bridge MCP BEGIN/END ===` 区块里加配置**：`scripts/setup-dsh.mjs` 会整体替换那段
2. **人格卡里不要写括号动作**（`（小声）`）：桥接会把括号内容当正文发出去
3. **改完 `config.json` 必须重启桥接**：白名单、端口、ffmpeg 路径都是启动时读的
4. **改人格卡不用重启**：每条消息重新读文件
5. **批处理文件必须是纯 ASCII**：cmd 用 OEM 代码页读中文会乱码
6. **写 JSON 不要带 BOM**：`Set-Content -Encoding UTF8` 会加 BOM，很多解析器不认
